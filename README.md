# 📝 React Blog UI

A simple and responsive Blog UI built using React.js.



## ✨ Features

- Responsive Blog UI
- Dynamic blog cards using `.map()`
- Reusable `BlogCard` component
- Separate blog data file
- Clean and simple UI
- Desktop, Tablet, and Mobile responsive

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Vite
- Google Fonts
- Git & GitHub
- Font awesome
- Vercel
